## 编写约定

- 每个模块目录都保留一个 `README.md` 作为索引。
- 子文档按职责拆分，避免把接口、模型、生命周期、取值策略和扩展规则堆在同一个文件里。
- 文档中的类名、接口名、缓存键和接口路径以当前代码为准；修改程序结构时应同步更新对应设计文档。
