# Javadoc 规范

> **Why**: Javadoc 是代码文档的核心，@since 标签追踪代码演进历史。
> **What**: 新增代码必须添加 Javadoc，保持历史版本可追溯。

---

## @since 标签规则

### 核心原则

| 场景           | Javadoc | @since   | 说明       |
|--------------|---------|----------|----------|
| 新增类/接口/枚举/注解 | 必须      | 必须       | 记录首次出现版本 |
| 修改已有类        | 必须      | **禁止更新** | 保持原版本追溯  |
| 新增方法/字段      | 必须      | 必须       | 记录首次出现版本 |
| 修改已有方法/字段    | 必须      | **禁止更新** | 保持原版本追溯  |
| @Override 方法 | 不需要     | 不需要      | 继承父类文档   |

**版本号格式**: `v7.{YY}{MM}{迭代}.{序号}` 如 `v7.260401.0`

---

## Javadoc 模板

### 方法 Javadoc

```java
/**
 * 方法功能简述
 *
 * @param param 参数说明
 * @return 返回值说明
 * @throws Exception 异常说明（必要时）
 * @since v7.260401.0
 */
```

### 参数说明要点

| 要素        | 说明    |
|-----------|-------|
| 是否能为 null | 必须说明  |
| 取值范围      | 必要时说明 |

## 常见错误

```java
// ❌ 缺少 @since
/**
 * 获取用户
 */
UserVO getUser(Long userId);

// ❌ 修改已有方法更新 @since

/**
 * @since v7.260402.0  // 错误
 */
UserVO getUser(Long userId);

// ✅ 正确

/**
 * 获取用户
 *
 * @param userId 用户ID
 * @return 用户信息
 * @since v7.260401.0
 */
UserVO getUser(Long userId);
```

## DO/DON'T 速查

| DO                 | DON'T                    |
|--------------------|--------------------------|
| 新增类添加 @since       | 修改已有类更新 @since           |
| 方法参数说明 null 情况     | 省略参数说明                   |
| @since v7.260401.0 | @since v7.260402.0（修改已有） |
