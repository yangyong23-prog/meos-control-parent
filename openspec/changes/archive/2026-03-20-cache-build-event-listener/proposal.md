# Proposal: Cache Build Event Listener

## Summary

实现应用内事件监听机制，当特定业务事件发生时，异步触发物理世界缓存构建，不阻塞主业务流程。

## Motivation

当前缓存构建需要通过 REST 接口手动触发，存在以下问题：
- 业务数据变更后，缓存无法及时更新
- 运维人员需要手动触发缓存构建，操作繁琐
- 缓存与实际数据存在延迟，可能影响业务判断

通过监听应用内事件自动触发缓存构建，可以实现：
- 数据变更后自动更新缓存
- 减少人工干预
- 提高缓存数据的实时性

## Goals

- 定义缓存构建触发事件 `CacheRwdBuildTriggerEvent`
- 实现事件监听器，异步执行缓存构建
- 支持指定 `runningMonitorType` 触发特定类型的缓存构建
- 不阻塞主业务流程，不等待缓存构建结果

## Non-goals

- 不支持批量触发多种类型的缓存构建
- 不提供事件触发的历史记录
- 不实现事件重试机制（依赖现有分布式锁保护）

## Scope

- 影响模块：`CacheRwdDomainService`、新增事件类、新增事件监听器
- 版本：`7.260320.0`
