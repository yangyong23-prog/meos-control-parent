# PRD: 云端IOT持久化信息点查询调用链路分析

## 需求背景

产品需求【PRD-260901】新增云端持久化数据查询规则，方案要点：

1. **壳配置新增分组"云端持久化数据显示规则"** — 两个配置项：持久化数据查询逻辑（默认"查询同一个时刻点的数据"，可选"查询距离当前最新的数据"）、距离当前的时间间隔（默认 1h，范围 1-168，仅最新数据模式出现）。
2. **前端请求头加标识** — 前端在冷热源相关接口请求头加标识 `removeDefaultIpType=true`（值必须为 true），后端在"请求头标识 + 壳配置最新数据模式"三条件满足时，按（当前时间-间隔 ~ 当前时间）查询且不传分精度 ipType；否则一切按现有逻辑执行。
3. **影响范围限定** — 冷源、冷热源、热源、空调冷源、空调热源、空调冷热源（空调系列暂不改动）。
4. **前端 API 入参保持不变** — 仅请求头新增一个标识；系统图/空间三维模型在最新数据模式下不显示"更新时间"。

## 分析范围

本次任务**仅进行现状分析**，不进行任何代码修改。分析完成后，将基于结果与前端团队对接，然后进行设计方案评审。

## 分析要求

1. 完整识别所有涉及云端 IOT 持久化数据查询的接口、方法和服务
2. 分析当前查询实时值的 ipType 和时间参数的使用情况
3. 记录所有相关的方法调用链路、参数传递路径和数据流向
4. 识别可能受此变更影响的业务功能模块
5. 整理出完整的接口清单和影响范围分析

## 输出交付物
