# 模板对象明细云端写入

## Goal

把模板对象明细生成接入云端增量重建，独立审核递归结果生成、完整范围替换和失败保旧，不切换读取。

## Dependencies

- 父任务：`07-13-cache-object-model-refactor`。
- 前置审核：子任务 01 至 08 已通过，直接依赖子任务 06、08。

## Requirements

- 继承父任务统一异常边界：业务校验和范围冲突使用带中英文资源的 `BusinessException`；JSON 转换统一使用 `ObjectMapperUtils` fail-safe，Converter 不自行捕获 Jackson 异常；读取方对 `null` 整批降级，写入方在删除前拒绝 `null`，Mapper 和事务异常不得吞掉。
- 复用对象云端重建上下文生成当前模板键的完整 `InfoCodeRwdObjectDetailDTO` 集合。
- 写入前复用子任务 06 的深拷贝和动态配置递归剥离能力。
- 以单模板键为原子替换范围，全部计算成功后才进入数据库事务。
- 远程查询、聚合、序列化或数据库失败时保留该模板键上一版结果并向上抛出。
- 初始化与增量事件后续必须调用同一明细生成能力。

## Out Of Scope

- 不修改信息点明细读取策略，不实时挂回动态配置。
- 不实现规则写入、XXL-JOB、READY 状态或路由。

## Acceptance Criteria

- [x] 模板保存/重建可生成完整明细范围，落盘 JSON 不含动态配置。
- [x] 模板范围替换失败时上一版仍完整可读。
- [x] 不重复实现第二套仅供初始化使用的生成逻辑。
- [x] 本任务 diff 只包含明细云端写入和聚焦测试。

## Review Gate

完成实现和质量检查后暂停，等待用户审核模板明细生成与失败语义；审核通过前不得开始子任务 10。
