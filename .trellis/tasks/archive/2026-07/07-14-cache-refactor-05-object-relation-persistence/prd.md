# 对象关系缓存持久化

## Goal

交付 `cache_object_rel` 的通用关系仓储，独立审核关系方向、替换范围和批量查询，不接入对象重建事件。

## Dependencies

- 父任务：`07-13-cache-object-model-refactor`。
- 前置审核：子任务 01 至 04 已通过。

## Requirements

- 新增关系实体、Mapper、XML 批量 SQL 和 Repository/Service 契约。
- 关系类型拆分为 `graph_code`、`rel_code`，同时保存主体对象 ID 和目标对象 ID。
- `object_id` 固定表示正向关系主体，`rel_object_id` 固定表示关系目标；反向查询只交换查询入口，不反转落库方向。
- 支持按 `(projectId, objectId, graphCode, relCode)` 完整范围原子替换，写入前按关系业务键去重。
- 支持正向和反向一次批量查询，查询必须命中各自索引且不得循环访问数据库。
- 仓储只处理明确范围，不在单键写入时判断或删除共享对象。
- 本子任务不新增测试代码；测试和完整验证统一在最终集成子任务执行，本阶段只做编译与静态检查。

## Out Of Scope

- 不处理 DTX 全量目标集合、对象孤儿清理或生产事件。
- 不实现模型视图、模板明细、规则或读取路由。

## Acceptance Criteria

- [x] 正向、反向批量查询契约均已实现。
- [x] 范围替换仅清理当前范围，其他范围和对象主表不受影响。
- [x] 大批量关系写入使用有界分片 SQL，无 N+1。
- [x] 本任务 diff 只包含对象关系持久化，不新增生产接线或测试代码。

## Review Gate

完成实现和质量检查后暂停，等待用户审核关系模型与范围替换；审核通过前不得开始子任务 06。
