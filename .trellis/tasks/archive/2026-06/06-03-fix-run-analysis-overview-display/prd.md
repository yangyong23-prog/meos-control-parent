# 修复运行复盘报告运行概述展示逻辑

## Goal

运行复盘日报的“运行概述”数据应严格遵循报告章节配置，避免展示未勾选章节的数据或未勾选系统实例的数据。

## Confirmed Facts

- 报告章节配置在生成时会过滤 `checked = "uncheck"` 的配置项。
- “项目用电量”已依赖“能耗分析”章节配置，未勾选时返回空数据。
- “本日用电预算”已依赖“能耗预算”章节配置，未勾选时返回空数据。
- “本日气象数据”和“运行标准”与报告章节配置无关，应默认展示。
- 当前“空间环境品质”在未勾选“环境品质”章节时仍会写入空 DTO，存在前端误展示风险。
- 当前“冷站运行结果”查询全量 ACAC 系统，未按“冷站系统运行实例”章节的勾选实例过滤。

## Requirements

- 运行概述中的“空间环境品质”仅在报告配置勾选“环境品质”章节时输出。
- 运行概述中的“冷站运行结果”仅包含报告配置中已勾选的冷站系统运行实例。
- 保持“项目用电量”“本日用电预算”“本日气象数据”“运行标准”的既有展示逻辑不退化。
- 修改范围限定在运行复盘报告运行概述计算/展示逻辑，不重构能耗分析、能耗预算、冷站系统运行章节本身。

## Acceptance Criteria

- [ ] 未勾选“环境品质”章节、无有效空间范围或无汇总数据时，运行概述 `spaceEnvironmentalQuality` 为 `null`。
- [ ] 勾选“环境品质”章节时，运行概述继续按配置空间范围计算空间环境品质。
- [ ] 未勾选任何“冷站系统运行实例”或无有效系统时，运行概述 `systemRunningResults` 为 `null`。
- [ ] 勾选部分“冷站系统运行实例”时，运行概述 `systemRunningResults` 仅包含这些实例对应的系统数据。
- [ ] “能耗分析”“能耗预算”章节未勾选时，运行概述对应字段仍为空；勾选时仍按既有逻辑计算。

## Out Of Scope

- 不调整前端展示组件。
- 不调整冷站系统运行章节详情页的数据生成逻辑。
- 不调整 CSV/Dify 的字段定义，仅依赖运行概述修复后的数据源。
